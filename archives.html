Sources & method.

masorah.io depends on manuscript repositories, photographers, editors, and open-data projects. Scans and page indexes are credited below. Where full text is available, it comes from UXLC (the corpus's own primary reference baseline — see /api/v1/corpus/structure), the Codex Sinaiticus Project transcription, Miqra according to the Masorah (MAM), diplomatic manuscript transcriptions from BIMA / Corpus Masoreticum, the DT-UCPH Samaritan Pentateuch, and lxx-morph, with Greek-to-Hebrew verse-number equivalences from STEPBible TVTMS. Each witness's detail card names the source used.

Verse-level transcriptions in this corpus's own 02_Forensic_Nodes come from a mix of repository OCR/transcriptions, HTR (Codex Sassoon 1053's own TesserACT + Dicta-HTR v2 pipeline — see architecture.html), and conservative text alignment. Scans remain with their repositories and are displayed here only for passage navigation, cropping, and verse highlighting; where a repository restricts embedding (e.g. Vaticanus, which opens only in the Vatican Library viewer) this Archive links out instead of hot-linking the image directly. Image rights and credits are stated per witness.
